# devops-lab

A simple base-level DevOps lab project with a Node.js service, Docker support, and CI automation.

## Included

- Minimal HTTP service in `app.js`
- Automated tests with Node's built-in test runner
- Docker image for local/containerized runs
- Docker Compose stack
- GitHub Actions workflow for CI

## Run locally

```bash
npm install
npm start
```

Then open:

- http://localhost:3000/
- http://localhost:3000/health

## Run tests

```bash
npm test
```

## Run with Docker

```bash
docker build -t devops-lab .
docker run -p 3000:3000 devops-lab
```

Or with Docker Compose:

```bash
docker compose up --build
```

## CI

The GitHub Actions workflow in `.github/workflows/ci.yml` runs the test suite on push and pull request events.
